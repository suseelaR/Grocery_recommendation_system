# Smart Grocery Helper

A customer-friendly grocery recommendation system using Association Rule Mining and Apriori Algorithm.

## 🌐 Live Application
[🔗 Open Live App](https://groceryrecommendationsystem.streamlit.app/)

## 🚀 Features
- Smart grocery suggestions
- Wishlist management
- Search history
- Popular products dashboard
- Interactive visualizations

## 🛠️ Technologies Used
- Python
- Streamlit
- Pandas
- Plotly
- Mlxtend
- Apriori Algorithm
